# Backend API

## Instrucciones para correr el proyecto

1. Instalar dependencias:
```bash
npm install
```
2. Inicializar la base de datos:
```bash
   npx prisma db push
```
3. Levantar el servidor:
```bash
npm run dev
```
En caso de querer ver BD en navegador
```bash
npx prisma studio
```
